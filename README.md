# Panorama del Nuevo PIM

Presentación interactiva y autónoma para revisar el panorama funcional del Nuevo PIM por feature, equipo, prioridad, dependencias y módulo.

## Sitio público

El sitio se publica mediante GitHub Pages desde `index.html`.

## Uso local

Abre `index.html` en un navegador moderno. La presentación conserva todos sus datos dentro del mismo archivo HTML; únicamente las bibliotecas React, Babel y GSAP se cargan desde CDN.

## Estado

Propuesta para revisión; no representa alcance aprobado.
